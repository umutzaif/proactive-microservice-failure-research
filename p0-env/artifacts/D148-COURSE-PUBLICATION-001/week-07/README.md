# D-148 Week 7 ACM-style draft candidate

This directory contains an English manuscript candidate, BibTeX references, and
an anonymized supplement candidate assembled from verified Weeks 3-6 outputs.
It is structured for later conversion to an ACM `acmart` manuscript, but it is
not yet LaTeX, a rendered PDF, an anonymized repository export, or a submission.

Verify from the repository root:

```powershell
python p0-env\scripts\verify-d148-week7-draft.py
```

The verifier checks section completeness, numerical claims, citation keys,
contribution boundaries, receipt limitations, and selected identity leaks. It
does not assess writing quality, venue fit, or double-blind compliance of Git
history. Those require human/adviser review and a later sanitized export.
