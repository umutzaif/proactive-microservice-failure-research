# D-148 Week 4 bounded manuscript sections

This directory contains repository-only English candidate sections for a future
course publication. It is a derived teaching artifact, not a canonical source,
submission package, or authorization to run an experiment.

The draft is deliberately bounded to claims C148-01 through C148-04. Claim
C148-05 remains held because the current worktree contains zero of the 21
expected final-receipt/SHA-manifest pairs. Claims C148-06 through C148-08 are
mandatory limitations, not optional editorial notes.

Verify the draft from the repository root with:

```powershell
python p0-env\scripts\verify-d148-week4-manuscript.py
```

The verifier checks numerical consistency against the Week 3 derived tables,
claim traceability, required limitations, and prohibited overclaims. It does
not establish publication readiness or replace peer review.
